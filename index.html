Как добавить урок

три шага

1Положить файл

Урок кладётся отдельной папкой, тогда ссылка короткая и красивая.

school-lessons/
├── index.html          ← этот каталог
├── lessons/
│   ├── phys-7-019/
│   │   └── index.html  ← урок
│   └── phys-7-047/
│       └── index.html
└── vendor/             ← общие библиотеки
lessons/phys-7-019/index.html

2Отметить готовым

В этом файле есть объект READY. Добавьте туда запись с кодом урока — карточка станет зелёной и получит кнопку «Открыть».

'phys-7-047': {
  href: 'lessons/phys-7-047/',
  candidates: [
    'lessons/phys-7-047/',
    'lessons/phys-7-047/index.html',
    'phys-7-047.html'
  ],
  interactive: 'Ванна с водой, стрелки сил',
  primitives: ['slider','vector','plot'],
  tasks: 4
}
const READY = { … }

3Опубликовать

  1. GitHub → Add file → Upload files, перетащить папку урока.
  2. Заменить корневой index.html этим каталогом.
  3. Commit changes, подождать минуту.
  4. Открыть каталог и нажать «Проверить ссылки».
Регистр важен: Index.html и index.html — разные файлы. Пути внутри уроков делайте относительными.
